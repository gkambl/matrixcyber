# matrixcyber

A cybersecurity **tower-defence game** built with React and TypeScript. Pick a mode, choose a difficulty, and play through levels in a campaign.

## Status
Early prototype. Only the app shell and game-state code were reviewed for this README, so it makes no further claims.

## Stack
React, TypeScript, Lucide icons.

Built by [Gouresh Kamble](https://github.com/gkambl).
